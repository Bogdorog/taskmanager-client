# Task Manager — Frontend

Клиентская часть веб-приложения для управления задачами с досками, компаниями
и настраиваемыми ролями участников и real-time уведомлениями.

<img width="896" height="856" alt="image" src="https://github.com/user-attachments/assets/bdcac457-20be-4674-8e02-e96bb12c389f" />


## Стек

- **React** + **TypeScript**
- **Vite**
- **React Query (TanStack Query)** — кэширование серверного состояния
- **Axios** — HTTP-клиент
- **MUI (Material UI)** — компоненты интерфейса
- **event-source-polyfill** — SSE-клиент с поддержкой кастомных заголовков
- **react-hot-toast** — уведомления в UI

## Требования

- Node.js 18+
- Запущенный backend (см. репозиторий `task-manager-backend`)

## Установка и запуск

```bash
npm install

npm run dev
```
